Code Defence 개인정보처리방침

최종 업데이트: 2026년 9월 10일

teopfgames(이하 “개발자”)는 Code Defence 이용자의 개인정보를 중요하게 생각합니다.

수집 및 공유

현재 비공개 테스트 버전의 Code Defence는 이용자의 개인정보를 개발자에게 수집하거나 제3자와 공유하지 않습니다. 광고, 분석, 로그인, 클라우드 저장, 원격 설정, 오류 보고 및 실제 결제 서비스는 연결되어 있지 않습니다.

기기 내 저장

게임 진행 상황, 설정 및 기록은 이용자의 기기 안에만 저장됩니다. 앱을 삭제하거나 기기 데이터를 초기화하면 해당 정보가 삭제될 수 있으며, 개발자는 이를 복구할 수 없습니다.

아동의 개인정보

Code Defence는 아동으로부터 개인정보를 고의로 수집하지 않습니다. 현재 버전은 개인정보를 수집하거나 공유하는 기능을 제공하지 않습니다.

외부 서비스 변경

향후 외부 서비스가 추가되어 개인정보 처리 방식이 바뀌는 경우, 해당 기능을 활성화하기 전에 이 방침과 Google Play의 데이터 보안 정보를 갱신합니다.
