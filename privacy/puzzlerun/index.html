Puzzle Run 개인정보처리방침

시행일: 2026년 10월 11일

티이오에프(teopf)가 제공하는 Puzzle Run(이하 “게임”)의 현재 Android 테스트 버전에 적용되는 방침입니다. 게임은 회원가입 없이 실행되며, 게임 진행 기록과 언어·설정 정보는 사용자의 기기에만 저장됩니다.

게임에서 처리하는 정보

게임은 이름, 이메일 주소, 전화번호, 정확한 위치, 연락처, 건강 정보 또는 광고 ID를 수집하지 않습니다. 게임 진행 기록과 설정은 기기 내부 저장소에 보관되며 개발자 서버로 전송되지 않습니다. Android 자동 백업은 사용하지 않습니다.

게임은 Firebase Remote Config를 사용하여 앱의 안전한 기본 설정을 받습니다. 이 과정에서 Google Firebase가 앱 설치별 식별자, 국가·언어·시간대, 기기 및 운영체제 정보, 앱·SDK 버전, Firebase 앱 식별자와 패키지 이름을 서비스 제공·유지·개선을 위해 처리할 수 있습니다. 이 정보는 HTTPS로 암호화되어 전송되며, Google의 개인정보처리방침과 Firebase 서비스 조건에 따라 처리됩니다.

현재 테스트 버전에는 광고, 인앱결제, 계정 동기화가 연결되어 있지 않습니다. Firebase Analytics와 Crashlytics 수집은 앱 설정과 원격 설정에서 모두 꺼져 있으며, 현재 버전은 사용 분석 이벤트나 충돌 보고를 전송하지 않습니다. 이 기능의 처리 범위가 달라지면 먼저 이 방침과 스토어의 데이터 보안 정보를 갱신합니다.

사용자가 선택하는 공유

사용자가 공유 기능을 누르면 게임이 현재 기기에서 공유 이미지를 만들고 Android 공유 메뉴를 엽니다. 공유 대상 앱을 선택하고 전송하는 것은 사용자의 선택입니다. 선택한 서비스에서의 정보 처리는 해당 서비스의 방침을 따릅니다. 게임 개발자는 공유 이미지를 자동으로 받거나 보관하지 않습니다.

문의와 삭제

게임 데이터는 앱을 삭제하거나 기기 설정에서 앱 데이터를 지우면 삭제됩니다. 별도 게임 계정이 없으므로 계정 삭제 절차는 필요하지 않습니다. 사용자가 이메일로 문의하면 문의 내용과 회신에 필요한 이메일 주소를 답변 및 문제 해결을 위해 처리하며, 법령상 보관 의무가 없는 한 처리 완료 후 삭제합니다.

아동 및 방침 변경

게임은 아동의 개인정보를 고의로 수집하지 않습니다. 데이터 처리 기능, 광고 또는 결제가 추가되거나 관련 정책이 변경되면 이 페이지의 시행일과 내용을 갱신합니다.
